# Operator guide

The bootable appliance is not ready for operators yet. This file reserves the final workflow:

1. Insert the verified HWScan USB.
2. Select it in the target PC's boot menu.
3. Wait for the scanner UI and review warnings.
4. Enter the optional asset tag/operator fields.
5. Export JSON and Excel to `HWREPORTS`.
6. Use **Export and shut down** before removing the USB.
7. Verify the manifest/checksum when transferring reports.

Until a release appears on the repository's Releases page, use only the fixture-driven development commands in the README.
