# Known limitations

- The current implementation consumes synthetic fixtures; it does not yet execute a complete real Linux scan.
- The Tk screen is a development shell, not the final Linux appliance UI.
- The Debian image configuration has not been built or booted.
- USB provisioning is deliberately inspection-only until a disposable USB and Linux test host are available.
- No claim is made about Secure Boot, legacy BIOS, sensor, fan, GPU VRAM, RAID, dock, or vendor-controller coverage.
- Inventory completion is not a diagnostic pass.
- Windows driver state, licensing, and Windows-only HWiNFO data are outside the scanner's scope.
